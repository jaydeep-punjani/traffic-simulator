# Getting help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/jaydeep-punjani/traffic-simulator/discussions).
- **Bugs:** open an [issue](https://github.com/jaydeep-punjani/traffic-simulator/issues/new/choose) with the bug report
  template. Include `trafficsim --version`, the scenario, the command you ran and the run's `summary.json` if you can.
- **Security problems:** do not open an issue; follow [SECURITY.md](SECURITY.md).

Before asking, check the [documentation](docs/README.md), especially
[Troubleshooting](docs/operations.md#troubleshooting) and [Compatibility](docs/compatibility.md).

This is a personal open-source project maintained in spare time, so replies may take a few days.
